# 쉬파리의 가든파티 🪰 *The Bluebottle's Garden Party*

우아한 영국 귀족 가든파티에 **초대받지 않은 쉬파리**가 되어, 점잔 빼는 손님들을 하나씩 질리게 하고
텅 빈 엉망진창 식탁 한가운데 **케이크** 위에 내려앉는 휴대폰 세로 화면용 3D 장난 액션 게임입니다.
아드만(《월레스와 그로밋》) 풍의 말랑하고 반질한 클레이 질감, 과장된 얼굴, 대사 없는 몸짓 연기를 목표로 만들었습니다.

## 바로 플레이

- **설치 없이**: [`docs/index.html`](docs/index.html) 파일 하나를 브라우저로 열면 됩니다 (단일 파일, 서버 불필요).
  GitHub Pages를 `docs/` 폴더로 켜면 휴대폰에서도 바로 플레이할 수 있습니다.
- **개발 서버**: `npm install && npm run dev` → 표시되는 주소(휴대폰은 같은 Wi-Fi에서 `--host` 주소)로 접속
- **빌드**: `npm run build` → 타입 검사 + Vite 빌드 + `docs/index.html` 단일 파일 생성

휴대폰 세로 화면 기준이며, 데스크톱 브라우저에서는 세로 비율 프레임 안에서 **마우스 클릭 하나**로 플레이합니다.
소리가 게임의 핵심이니 꼭 소리를 켜 주세요.

## 조작

조작은 **탭(클릭) 하나**뿐입니다.

| 탭한 곳 | 결과 |
| --- | --- |
| 식탁·음식·잔·코·머리·쟁반·잔디 | 즉시 튀어 나가 살짝 비틀린 곡선으로 쌩 날아가 착지 (착지하면 앞발을 비빔) |
| 허공 | 그 자리에서 윙윙 맴돌기 (시끄럽다!) |
| 날아가는 도중 다시 탭 | 관성을 살린 채 즉시 방향 전환 |

- **날면 윙윙** — 손님들이 소리를 듣고 고개를 돌립니다. 귀 옆을 스치면 소리가 커졌다 작아집니다.
- **앉으면 조용** — 조용히 앉아 있으면 손님들은 곧 관심을 잃습니다.
- 손님이 **신문을 말아 쥐거나 무기를 들면** 바닥에 경고 원이 생깁니다. 원이 **빨갛게 고정되면** 다른 곳을 탭해 피하세요. 아슬아슬하게 피하면 보너스!

## 목표

- 오후 3시에 시작하는 다과회가 **오후 5시 케이크 커팅** 전에, 손님 6명을 모두 질리게 해 쫓아내고 케이크 위에 내려앉으면 승리
- 목숨은 3개 (얻어맞거나… 먹히면 하나씩 잃음). 모두 잃거나 5시가 되면 실패 → 바로 재도전

## 손님들

| 손님 | 성격 |
| --- | --- |
| 크럼프 대령 | 깐깐해서 금방 질리지만 말아 쥔 《더 타임스》 반격이 번개 같다. 빗나갈수록 더 화가 난다 |
| 플럼트리 목사 | 무던한 대식가. 좀처럼 질리지 않지만, 그가 파리 앉은 음식을 먹는 모습은 남들을 질리게 한다 |
| 그림스비 노부인 | 귀가 어둡고 꾸벅꾸벅 존다. 귀에 댄 보청 나팔만은 조심 |
| 프루던스 양 | 결벽증. 가장 먼저 질리지만 비명을 지르며 허우적거린다 |
| 폽스워스 경 | 허영심 많은 멋쟁이. 하얀 양복에 얼룩이 묻으면 못 견딘다. 머리 위의 그것은… |
| 하이아신스 부인 | 안주인. 손님이 떠나고 파티가 엉망이 될수록 체면이 무너진다 |
| 집사 홉스 | 쟁반을 들고 식탁을 돈다. 떠나지는 않지만 훌륭한 소동 재료 |

## 장난은 정해진 목록이 아니라 세계의 반응입니다

모든 휘두르기는 물리적인 사건이라 **맞은 자리에 있던 것**에 영향을 줍니다 — 파리, 음식, 잔, 케이크, 옆 사람의 머리, 집사의 쟁반.
음식은 튀어 날아가 다른 손님에게 떨어지고, 쏟아진 와인은 식탁보에 스며 잔디에 미끄러운 웅덩이를 만들고,
그 광경을 본 사람들은 고개를 돌려 함께 질려 갑니다. 엉망이 된 식탁은 끝까지 그대로 남습니다.

예를 들어 이런 일들이 일어날 수 있습니다 (게임 안 **장난 도감** 18종):
코끝에 앉아 사팔눈 만들기, 코에서 버티다 제 뺨 때리게 하기, 재채기 폭탄, 와인잔에서 기다렸다가 와인 뿜게 하기,
옆 사람 머리 위에 앉아 엉뚱한 사람 맞히기, 젤리 모자, 파리 반찬, 포크에 실려 가다 입 앞에서 탈출, 미끄덩, 집사 와르르,
보청 나팔 대소동, 가발 실종, 도미노 구역질, 축음기 나팔 확성기…

## 기술 메모

- Three.js + TypeScript + Vite, 외부 에셋 없이 **모든 모델·텍스처·사운드를 코드로 생성**
  - 클레이 질감: 절차적 지문/주무름 노멀맵 + 물리 기반 재질, 정적 장식은 재질별로 병합해 드로우콜 절감
  - 얼굴: 표면을 따라 휘는 절차적 입 메시, 눈꺼풀/눈썹/볼 부풀기/초록빛 메스꺼움 블렌딩, 2-본 IK 팔
  - 소리: Web Audio로 합성한 날갯소리(귀 근처 근접 증폭 + 도플러 + 축음기 나팔 공명), 포먼트 합성 무대사 음성,
    파티가 무너질수록 늘어지고 튀는 축음기 미뉴에트(Petzold, 퍼블릭 도메인)
- 구조: `src/fly`(비행), `src/actors`(손님 AI·리그·표정), `src/world`(식탁·음식·얼룩·투사체), `src/game`(규칙·카메라·장난 도감), `src/audio`, `src/ui`
